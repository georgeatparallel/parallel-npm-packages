# @parallel-web/ai-sdk-tools

AI SDK tools for Parallel Web.

## Installation

```bash
npm install @parallel-web/ai-sdk-tools
# or
pnpm add @parallel-web/ai-sdk-tools
# or
yarn add @parallel-web/ai-sdk-tools
```

## Usage

```typescript
import { hello } from '@parallel-web/ai-sdk-tools';

console.log(hello('World')); // Hello, World!
```

## Development

This package is part of the `@parallel-web` monorepo.

### Build

```bash
pnpm build
```

### Development Mode

```bash
pnpm dev
```

### Type Checking

```bash
pnpm typecheck
```
